Banking System By Hadi Ahmed Alvi

Features
• Classes for Customer, Account, Transaction
• Create and manage customers and accounts
• Deposit, withdrawal, and fund transfers
• Transaction history with recent transactions view
• Display account balance and transaction details

Instructions: For running the code, open the visual studio solution in the task files and then press F5 to run them. If u are using any other IDE then open the main.c in each of the task subfolder and run the code in the IDE
