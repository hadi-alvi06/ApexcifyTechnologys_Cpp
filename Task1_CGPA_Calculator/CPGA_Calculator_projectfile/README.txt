Task 1 :CGPA Calculator 

Features
• Takes multiple courses as input
• Allows entering course name, credit hours, and grade
• Calculates GPA for the current semester
• Calculates overall CGPA using previous CGPA
• Displays academic standing (Excellent, Very Good, etc.)

Instructions: For running the code, open the Visual Studio solution in the task files and then press F5 to run them. If you are using any other IDE then open the main.cpp file in the task subfolder and run the code in the IDE.
