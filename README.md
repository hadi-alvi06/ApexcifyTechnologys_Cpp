# ApexcifyTechnologys C++ Internship

This repository contains my internship tasks completed for ApexcifyTechnologys using C++.

**Task Completed:**

**Task 1: CGPA Calculator**
- A simple Command Prompt based c++ program that takes multiple courses info, calculates gpa and displays the academic standing.

**Task 2: School Management system**
- A simple C++ system for school management, featuring user registration, duplicate validation, and file-based credential storage

**Task 3: Banking system**
- An OOP-based Banking System featuring Customer and Account management, secure fund transfers, and transaction details.

**Instructions:**
For running the code, open the visual studio solution in the task files and then press F5 to run them. If u are using any other IDE then open the main.c in each of the task subfolder and run the code in the IDE
